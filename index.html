Questions people ask first

What is the Vibe Code Checklist?

It is a public preflight list for a vibe-coded web app: pages, search, generative and chat discovery, legal pages, appearance, accessibility, performance, security, forms, accounts, and the README.

What does the prompt change in my app?

It writes one file, vibe-audit.html, at the workspace root. Application code stays as it is. You read the scorecard and decide what to fix.

Where do my checks go?

Ticks stay in local storage in this browser. The site does not receive them. Download the HTML report when you want a file.

What does a real report show?

A score of items in place over items that apply, then every check with a status, the reason it matters, and the evidence. The sample report shows the shape with fictional results.
