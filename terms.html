Terms of service

The Vibe Code Checklist is a guide for reviewing a web app you or your tools have built. The current version is the public repository and the website served from it.

What it is

You can read the list, tick it by hand, or paste the audit prompt into a coding agent such as Claude, Claude Code, or Cursor. The prompt tells that agent to write a report file and to leave application code as it is. You are responsible for the instructions you give an agent and for reviewing any file it writes.

What it is not

The checklist is not legal advice, a penetration test, or a promise that an app is finished, lawful, accessible, or secure. A high score means the listed evidence was present. It does not certify the product.

Reports

Do not publish a report that contains secrets. The audit procedure tells the agent to name a file and the kind of secret, not the secret itself. You still need to read the file before you share it.
