Paste the prompt

  1. Open your app in your editor. Leave this repo closed.
  2. Copy the prompt and paste it into the chat. The editor reads what you are building, then skips checks that app does not need.
  3. Open vibe-audit.html in your project when it finishes.

The prompt

Audit this workspace against the Vibe Code Checklist.

First read this workspace and say what the app is for: the end goal, who it is for, and which features it actually has. Then judge only the checks that fit that app. A check the product does not need is not a failure.

Source of truth (read these before judging anything):
https://github.com/Delexoo/vibe-code-checklist/blob/main/PROMPT.md
https://github.com/Delexoo/vibe-code-checklist/blob/main/checklist.json

Follow PROMPT.md exactly. Inspect THIS workspace, not the checklist repo. Write a self-contained vanilla HTML report at vibe-audit.html showing what passed, what is missing, and what does not apply. Do not change application code.

The editor writes that one file and leaves the rest of the app alone. See a sample report. The results in it are made up.
