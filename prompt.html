The prompt

What it checks

A check the product does not need is set aside. These are the kinds the agent looks for.

  1. Pages and flows

    A missing page, an empty screen, a loading state, an error, and a confirmation after a form or a payment. The price is shown before anyone is charged.

  2. Search

    Each public page has its own title and description, one clear heading, alt text, a canonical address, social cards, a sitemap, and robots.txt. Articles show a date.

  3. Assistants

    A short account of who this is, what it does, and who it is for, with facts that are safe to quote and structured data for the main thing the site is about.

  4. Answers

    The first screen answers what this is. The name and the facts stay the same from page to page. Question-style headings are there when the page is answering something.

  5. Legal and consent

    Privacy, terms, a cookie choice, a way to reach a person, licensed images and fonts, real reviews, a refund rule if you charge, and a way to report posts or uploads.

  6. Identity

    A favicon, a theme color, a phone layout, readable contrast, a visible keyboard focus, and reduced motion when someone asks for it.

  7. Looks designed

    Neutral surfaces, one set of icons, spacing on one scale, and plain copy. The first view looks like this product, not a generic template.

  8. Interface details

    Loading that matches the layout, tap targets larger than the icon, safe areas, stable numbers, and, in an app used every day, undo, shortcuts, and a command menu.

  9. Accessibility

    A language, a skip link, keyboard access, links that say where they go, and a meaning that is not carried by color alone.

  10. Performance

    Compressed images that reserve their space, a first page that is not a huge script, and text that stays visible while a font loads.

  11. Security

    No secrets in the repo, HTTPS, private routes, escaped visitor text, hashed passwords, a price the server looks up, and limits on sign-in, uploads, and paid calls.

  12. Forms

    Every field has a label. An error sits with the field that failed. A slow submit cannot be sent twice. A success is confirmed in words.

  13. Accounts

    Settings, a way to sign out, an age check, a verified email, a reset link that expires, a minimum password length, and a way to delete personal data.

  14. Project hygiene

    A README that says how to run the app, a test for a behavior that matters, packages on a supported version, and backups if there is a database.

A shipping guide. Not a legal opinion or a security guarantee.
